# SSM087 流程停留时长记录器

一个 Chrome / Edge 浏览器扩展，自动记录网址包含 `SSM087` 的流程详情页停留时长，并按「流程编号 + 项目号 + 日期」汇总成表格（数据四列 + 操作列）。

## 功能

- **只在该页面生效**：网址含 `SSM087`，**且页面可见文本里能看到完整的「同意，提交」**才计时。
  - 只取**可见文本**（`innerText`），**不读隐藏元素**（不用 `textContent`）——MvcSheet 会把所有按钮都渲染进 DOM 再用样式隐藏，若读隐藏文字会在按钮只显示「同意」/「催办」时误计时。**只有真正看得到完整「同意，提交」才算**（按钮只写「同意」不算）。
  - 兼容全角/半角逗号及逗号两边空白，如「同意，提交」「同意,提交」「同意 ， 提交」；「同意 提交」（无逗号）、只有「提交」不算。
- **「催办」页面不计时**：页面可见的「催办」按钮（`span.toolText` 文本为「催办」，或 `i.fa-bullhorn` 喇叭图标）存在时**完全不计时、不写记录**，即使同时有「同意，提交」。
- 上述任一门控不满足时均不累加时间，但**左下角悬浮窗始终显示已累计的真实时间**（绝不清零），只在标题旁用小标签标注「●计时中 / ⏸未计时（原因）」；状态标签带 3 秒粘滞，避免按钮状态来回变化时闪烁。
- **流程编号自动识别**：兼容两种页面渲染：
  - 只读态：`#control1` 内隐藏 input + `<label><span>流程编号值</span></label>`（取 span 文本）
  - 编辑态：`#control1` 内 `input[data-datafield="liuchengbianhao"]`（取 input 的 value）
  - **读不到会自动重试**：页面加载慢时编号字段可能迟迟不渲染，此时会**每隔 4 秒重试一次，最多 5 次**（悬浮窗显示「识别流程编号中 n/5」）。重试期间时间先暂存，不会提前写盘。
  - **5 次仍取不到**才归入「（未识别流程）」，可在面板点它手动改正（无需解锁）。归入后仍会在后台低频重试，一旦读到正确编号就自动把未识别时间**按天合并**到真编号，避免刷新后出现「未识别 + 真编号」两条记录。
- **项目号自动识别**：取 `input[data-datafield="xiangmuhao"]` 或 `div[data-title="项目号"]` 内的值（兼容 `label>span` 只读态），与流程编号绑定存储，作为表格第二列。
- **计时规则**：
  - 页面可见时计时；**切到其他标签页 / 最小化窗口时暂停**（不会把时间记到后台或别的流程表单上）。
  - **切到其他程序、浏览器窗口仍可见时继续计时**（blur 不暂停）。
  - 回到标签页时重新起算，后台时间不计入。
  - 每 5 秒落盘一次，关闭/刷新页面时也会结算。
- **「切标签继续计时」复选框（面板标题右侧，勾选状态会被记住）**：
  - 勾选后，切换到其它标签页查资料时**当前流程仍在后台计时**，直到开始给另一条流程计时，或关闭本标签才停止；悬浮窗状态会显示「●计时中（后台）」。
  - **加载阶段也计时**：新流程页还在加载（表单未渲染）时的时间会先暂存，悬浮窗显示「⏳加载中（时间暂存）」。加载完成后：
    - 本页需要计时（有「同意，提交」）→ 暂存时间归本页，本页接管计时，原后台流程立即停止；
    - 本页不需要计时（如只有「催办」）→ 暂存时间归还给刚被挤到后台的那条流程，本页保持停止。
  - 已经让位的页面在用户切回来且本页可计时时会**重新抢占**，确保「切到新的计时 → 停旧的、记新的」。
  - 同一时刻只允许一条流程处于后台计时：另一条 SSM087 流程开始计时后，本页自动让位并结算，悬浮窗显示「⏸已停止（另一流程计时中）」。
  - 取消勾选后恢复默认规则（切标签即暂停）。切换勾选状态会重置跨标签归属；已累计时间不会丢失。
- **表格五列**：流程编号、项目号（第二列）、日期、当天累计停留秒数、操作；面板顶部可按日期筛选，**只显示选中那一天的记录**（默认今天，可用 ‹ › 翻页 / 日期选择器 / 「今天」按钮切换）。
- **时长按整秒计算**：所有显示的秒数、编辑输入、CSV 导出均四舍五入到整秒；面板底部**合计用 `hh:mm:ss` 格式**（如 `02:02:02`）。
- **表格一页最多 8 行**：表头固定（sticky），超过 8 条时**只在表格区域内滚动**查看；整个弹窗不再出现外层滚动条。
- **修正「(未识别流程)」编号**（无需解锁，直接可用）：
  - 流程编号为「**(未识别流程)**」的行，其编号**始终可点击**，点它直接弹出输入框录入正确编号（只有这一次机会——改完编号就不再是"未识别"）。
  - 记录与项目号一并迁移到新编号；若新编号已存在，同一天的秒数会累加合并，不丢数据。
- **修改/删除单条记录**（默认隐藏，防止误操作）：
  - **连续点击面板标题「变更流程处理时长」5 次**（2 秒内）临时开启编辑模式，再点 5 次关闭；**关闭面板后自动失效**，下次打开又是隐藏状态。
  - 开启后：**点击流程编号**修改编号；**点击秒数**变成输入框，回车/失焦保存为整秒；点「**删**」删除该条（某流程某天）。
- **导出全部 CSV**：四列（流程编号,项目号,日期,停留时长(秒)）；不受日期筛选影响，始终导出所有日期、所有流程的完整记录；带 BOM，Excel 直接打开不乱码。
- **导出 / 导入 JSON**（完整备份与恢复）：
  - 「导出 JSON」把 `records` + `flowProjects` 一起存成一个 `.json` 备份文件。
  - 「导入 JSON」选择备份文件，**确认后用备份覆盖当前全部数据**（需二次确认）；导入后请刷新已打开的详情页以同步悬浮计时。这是换电脑 / 换浏览器时迁移数据的推荐方式。
- **左下角悬浮计时**：在符合条件的流程详情页左下角实时显示**当前流程自己的**停留时间（流程编号、项目号、今日 `时:分:秒(秒数)` + 累计），每秒刷新；时间始终为真实累计值，不随门控状态清零或来回跳。
- **清空记录**：需二次确认（同时清空项目号映射）。

## 安装（开发者模式加载）

1. 打开 Chrome / Edge，地址栏输入：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
2. 打开右上角「**开发者模式**」开关。
3. 点击「**加载已解压的扩展程序**」，选择本文件夹 `ssm087-dwell-recorder`。
4. 浏览器工具栏会出现扩展图标，点击即可查看统计面板。

> 首次使用请在目标流程详情页停留几秒，数据每 5 秒落盘一次；面板与左下角悬浮计时每秒实时刷新。修改扩展文件后需到扩展管理页点「重新加载」，**并刷新已打开的流程详情页（F5）**——否则旧页面里的脚本会因扩展上下文失效而停止计时（脚本已做保护，不会报错，悬浮层会提示刷新）。

## 数据存储

记录保存在浏览器本地 `chrome.storage.local`：

- `records`：停留秒数（底层以毫秒浮点累计，显示/导出时按整秒四舍五入），结构 `{流程编号: {YYYY-MM-DD: 秒}}`
- `flowProjects`：流程编号对应的项目号，结构 `{流程编号: 项目号}`
- `keepTimingWhenHidden`：面板「切标签继续计时」复选框的勾选状态（布尔值，记住用户选择）
- `activeTiming`：后台计时模式下的跨标签归属 `{ runId, processNo, ts }`，保证同一时刻只有一条流程在后台计时（带心跳，失效后自动释放）

```json
{
  "records": {
    "SM087-RICH-20260817876": { "2026-11-17": 128.4 }
  },
  "flowProjects": {
    "SM087-RICH-20260817876": "22P013"
  }
}
```

清除浏览器站点数据 / 扩展数据会一并清空记录；建议需要留存时用「导出 JSON」完整备份（含项目号映射），迁移时用「导入 JSON」恢复。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | 扩展配置（Manifest V3） |
| `content.js` | 页面内采集脚本：提交按钮门控、识别流程编号/项目号、计时、写入存储、左下角悬浮计时 |
| `popup.html` / `popup.css` / `popup.js` | 点击图标弹出的面板：按日期筛选的四列表格、CSV/JSON 导出、JSON 导入、连点标题解锁编辑删除、清空 |
